# DecodeLabs Task 1 - Random Number Guessing Game

## Description

A JavaFX GUI-based Random Number Guessing Game developed in Java. It allows users to guess a random number with interactive feedback through a graphical interface.

This project was developed as part of the DecodeLabs Internship Program. It demonstrates Java programming concepts, JavaFX GUI development, event handling, and basic game logic.

## Features

- JavaFX Graphical User Interface (GUI)
- Random number generation
- User friendly interface
- Interactive feedback for each guess
- Input validation
- Displays success message when the correct number is guessed
- Simple and easy-to-use design

## Technologies Used

. Java
. JavaFX
. NetBeans IDE

## How to Run

1. Open the project in NetBeans IDE.
2. Build the project.
3. Run the application.
4. Enter your guess in the input field.
5. Follow the feedback until you guess the correct number.

## Project Purpose

The purpose of this project is to practice Java programming, JavaFX GUI development, event handling, and random number generation by creating an interactive guessing game.
